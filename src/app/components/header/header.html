計算ロジック ＆ シミュレーション仕様ガイド

1. 1年目（単年度）最適化モデル（OR-Tools）

各社員の能力値（営業・管理・開拓・育成）に事業部ごとの「評価重み」を乗じて個人貢献度を算出し、全社の合計売上・利益が最大化となる配属を数理最適化で求めています。

社員貢献度 = 営業力×w_s + 管理力×w_m + 開拓力×w_d + 育成力×w_t
基本売上 = 基準売上 × [1 + (事業部能力値 / 100) × 成長係数]

2. 事業部別パラメータ仕様

事業部 評価重み (営業 / 管理 / 開拓 / 育成) 基準売上 成長係数 適正 / 最低人数
A事業部 (飽和) 0.45 / 0.35 / 0.10 / 0.10 10 億円 0.06 40名 / 30名
B事業部 (成長) 0.35 / 0.20 / 0.30 / 0.15 7 億円 0.12 35名 / 20名
C事業部 (新規) 0.20 / 0.10 / 0.50 / 0.20 2 億円 0.25 25名 / 10名

3. 充足率ペナルティ ＆ コスト算出ルール

最終売上は、適正人数に対する配属充足率（配属人数 / 適正人数）に応じた補正係数を乗じて補正します。

  • 不足ペナルティ（70%未満時）: A事業部 ×0.30 / B事業部 ×0.50 / C事業部 ×0.70
  • 過剰ペナルティ: 120%〜140% (×0.95) / 140%〜160% (×0.90) / 160%以上 (×0.80)
  • 全社コスト: 各種福利厚生・管理費用を含めるため 「人件費 × 3倍」 で算定
  • 利益: 全社最終売上 − 事業部人件費コスト計

4. 中長期（2〜5年目）成長シミュレーションモデル

1年目の算出結果（最終売上）をベースとし、配属された社員の「平均育成力」による成長ボーナスを加算して複利成長を試算します。

事業部年成長率(g) = 基本年率(A:2%, B:8%, C:20%) + (平均育成力 / 100 × 0.05)
t年目売上 = (t-1年目売上) × (1 + g)
※ 平均育成力が100の場合、事業部の成長率が最大+5%上乗せ（平均70なら+3.5%加算）されます。
